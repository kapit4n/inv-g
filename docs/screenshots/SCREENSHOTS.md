## Regeneration

To regenerate all screenshots:

```bash
cd scripts/screenshots
npm install
npx playwright install chromium
THEME=all npx playwright test --config playwright.config.ts
```

Or use the master runner:

```bash
npx tsx scripts/screenshots/generate_all.ts
```

### Prerequisites

- App running in dev mode (`npm run dev:tauri`)
- Demo data seeded (automatic on first run or via UI "Seed Demo Data")
- Spanish locale enabled
- Playwright and Chromium installed

### Notes

- Screenshots are taken at 1920×1080 with maximized window
- Light and dark themes are generated separately
- All UI text is in Spanish
- Charts are waited for before capture
- Notifications are dismissed before capture
- Forms are filled with realistic demo data before capture
