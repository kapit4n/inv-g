# Inventory Gear

> Modern desktop inventory and point-of-sale application for automotive parts stores.

## Overview

Inventory Gear is a production-quality desktop application built with Tauri v2, React, TypeScript, and SQLite. It's designed for auto parts stores, mechanics, car workshops, and automotive distributors.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Desktop Runtime | Tauri v2 |
| Frontend | React 19, TypeScript, Vite 8 |
| Styling | TailwindCSS v4, shadcn/ui patterns |
| State | Zustand, TanStack Query |
| Forms | React Hook Form, Zod |
| Database | SQLite, Drizzle ORM |
| Backend | Rust |
