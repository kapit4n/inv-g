# Receipts

## Overview

The Receipts module manages all sales receipts generated by the system. It allows viewing, reprinting, and tracking receipt print status for sales and refunds.

## Features

### Receipt List
- Paginated table with columns: Receipt Number, Sale Number, Customer, Type, Printed Status, Created At.
- Search by receipt number or sale number.
- Filter by receipt type, printed status, date range.

### Receipt Types
- **Sale Receipt** — Generated automatically on POS checkout.
- **Refund Receipt** — Generated when a return is processed.
- **Quote Receipt** — Generated when printing a quote.
- **Invoice** — Detailed invoice document.

### Receipt Detail
- Full receipt preview with:
  - Company header (name, address, tax ID from settings).
  - Receipt number and date.
  - Customer name (if selected).
  - Itemized list of products with quantities, prices, and line totals.
  - Subtotal, discount, tax, grand total.
  - Payment methods and amounts.
  - Change amount (if cash payment).
  - Footer with thank-you message and return policy.

### Print Management
- **Mark as Printed** — Toggle print status for tracking.
- **Reprint** — Send the receipt to the configured printer.
- **View** — Display receipt in browser for screen preview.
- **PDF Export** — Download receipt as PDF.

## Available Actions

| Action | Description |
|--------|-------------|
| View Receipt | Preview the full receipt |
| Print / Reprint | Send receipt to printer |
| Mark as Printed | Manually update print status |
| Export to PDF | Download receipt as PDF |
| Export List | Export receipt list to CSV/XLSX |

## Validation Rules

- Each sale generates exactly one receipt.
- Refund receipts are linked to the original sale receipt.
- Receipts are read-only after generation — no editing.

## Known Limitations

- No receipt template editor (layout is fixed).
- No email receipt delivery (print-only).
- No bulk reprinting of multiple receipts.
- Receipt paper size is configured per printer, not per receipt type.
