# Reports & Analytics

## What is it?

The Reports module provides comprehensive business intelligence — from executive dashboards to detailed analytics across all modules.

![Reports](/screenshots/light/41-reports-executive.png)

## Report Types

| Report | Route | Purpose |
|--------|-------|---------|
| [Executive Dashboard](/reports/) | `/reports` | Business overview with KPIs |
| [Sales Reports](/reports/sales) | `/reports/sales` | Revenue, trends, by-cashier |
| [Inventory Reports](/reports/inventory) | `/reports/inventory` | Stock valuation, aging, status |
| [Purchasing & Profitability](/reports/purchasing) | `/reports/purchasing` | Procurement, profit margins |
| [Customer & Supplier Reports](/reports/customers-suppliers) | `/reports/customers` | Customer/supplier analytics |
| [KPIs & Custom Reports](/reports/kpis-custom) | `/reports/kpis` | Key performance indicators |

## Executive Dashboard

The main reports page shows:
- Revenue and profit trends
- Top products, customers, suppliers
- Inventory health
- Sales by payment method
- Category performance

## Features

### Date Range Filtering
All reports support custom date ranges for analysis.

### Export
Reports can be exported for external analysis.

### Charts
Visual charts accompany most reports for quick understanding.

### Scheduled Reports
Set up automated report generation on a schedule.
