# Inventory Reports

## What is it?

Analytics for stock levels, valuation, movements, and inventory health.

## Available Reports

| Report | Content |
|--------|---------|
| Stock Valuation | Total inventory value at cost |
| Stock by Category | Value breakdown by category |
| Stock Status | In-stock, low-stock, out-of-stock counts |
| Stock Aging | How long items have been in stock |
| Movement Summary | Stock in/out/adjustment totals |
| Movement by Product | Per-product movement history |
| Dead Stock | Products with no recent sales |

## How to Access

**Sidebar → Reports → Inventory**. Route: `/reports/inventory`.

## Key Metrics

- **Total Stock Value** — Current cost value of all inventory
- **Turnover Rate** — How quickly stock sells and replenishes
- **Dead Stock %** — Percentage of stock with no recent movement
- **Shrinkage** — Unexplained stock decreases
