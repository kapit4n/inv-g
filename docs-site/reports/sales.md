# Sales Reports

## What is it?

Detailed analytics of sales performance, trends, and breakdowns.

## Available Reports

| Report | Content |
|--------|---------|
| Sales Overview | Total revenue, transaction count, average ticket |
| Sales by Period | Daily, weekly, monthly trends |
| Sales by Cashier | Performance per staff member |
| Sales by Payment Method | Cash, card, transfer breakdown |
| Sales by Category | Revenue per product category |
| Discount Analysis | Discount usage and impact |
| Returns Summary | Return volume and reasons |
| Tax Summary | Tax collected by period |

## How to Access

**Sidebar → Reports → Sales**. Route: `/reports/sales`.

## How to Use

1. Select the **report type**
2. Set **date range** (default: current month)
3. Apply **filters** (cashier, payment method, category)
4. View **charts and tables**
5. **Export** if needed
