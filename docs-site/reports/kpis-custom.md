# KPIs & Custom Reports

## What is it?

Key Performance Indicators for business health, plus custom and scheduled report generation.

## KPI Dashboard

### What is it?

A dashboard of key business metrics at a glance.

### Available KPIs

| KPI | Description |
|-----|-------------|
| Revenue | Total sales revenue |
| Profit Margin | Gross profit percentage |
| Inventory Turnover | How fast stock sells |
| Average Ticket | Average sale value |
| Customer Acquisition | New customers per period |
| Stock Accuracy | Inventory accuracy rate |

## Custom Reports

### What is it?

Build custom reports by selecting specific metrics, dimensions, and filters.

### How to Create

1. Go to **Reports → Custom**
2. Select **metrics** (revenue, quantity, margin)
3. Choose **dimensions** (product, category, period)
4. Apply **filters** (date range, status)
5. View and export

## Scheduled Reports

### What is it?

Automate report generation on a recurring schedule.

### How to Set Up

1. Go to **Reports → Scheduled**
2. Click **+ New Schedule**
3. Select **report type**
4. Set **frequency** (daily, weekly, monthly)
5. Set **recipients**
6. Save

## Exports

### Available Formats

- **CSV** — For spreadsheet analysis
- **PDF** — For sharing and printing

### How to Export

1. Open any report
2. Click **Export**
3. Select format
4. Download
