# Settings

## What is it?

User-level preferences for language, theme, and display options.

## How to Access

**Sidebar → Settings**. Route: `/settings`.

## Available Settings

| Setting | Options |
|---------|---------|
| Language | English, Español |
| Theme | Light, Dark, System |
| Date Format | Various formats |
| Time Format | 12h, 24h |

## How to Modify

1. Go to **Settings**
2. Change your preferred options
3. Changes apply immediately
