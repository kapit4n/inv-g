# Help

## What is it?

Built-in help and support resources within Inventory Gear.

## How to Access

**Sidebar → Help**. Route: `/help`.

|----------|-------------|

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Open command palette |
| `Ctrl + /` | Quick search |
| `Esc` | Close dialog/modal |
| `Enter` | Confirm action |

## FAQ

### How do I reset my password?
Contact your administrator. Passwords cannot be self-reset.

### How do I add a new product?
Go to **Inventory → Products → New Product**.

### How do I process a return?
Go to **Sales → Returns**, find the original sale, and process the return.

### How do I backup my data?
Go to **Administration → Backups → Create Backup**.
