# System Settings

## What is it?

Configure application-wide settings including business info, tax rates, printing, and integrations.

## How to Access

**Sidebar → Administration → Settings**. Route: `/admin/settings`.

## Settings Groups

| Group | Content |
|-------|---------|
| Business | Company name, address, tax ID, logo |
| Tax | Default tax rates, tax-inclusive pricing |
| Currency | Currency symbol, decimal places |
| Receipts | Receipt header/footer, printer settings |
| Notifications | Email/SMS notification preferences |
| Security | Session timeout, password policy |

## How to Modify

1. Go to **Admin → Settings**
2. Navigate to the relevant **group**
3. Modify values
4. Click **Save**

## Considerations

- Some settings require Admin or Owner role
- Changes apply immediately system-wide
- Business info appears on receipts and reports
- Tax settings affect all price calculations
