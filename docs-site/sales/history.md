# Sales History

## What is it?

Sales History shows all completed transactions with search, filter, and detail views.

![Sales History](/screenshots/light/15-sales-history.png)

## How to Access

**Sidebar → Sales → Sales History**. Route: `/sales`.

## Features

### Viewing Sales

The sales list shows:
- Sale number
- Date and time
- Customer name (if assigned)
- Total amount
- Payment method
- Status

### Searching Sales

- **Search bar** — By sale number, customer name
- **Date filter** — Filter by date range
- **Status filter** — Filter by completed, refunded
- **Payment method** — Filter by cash, card, transfer, credit

### Sale Detail

Click any sale to see:
- Line items with quantities and prices
- Discounts applied
- Tax breakdown
- Payment details
- Receipt (printable)
- Refund status

## How to View a Sale

1. Go to **Sales History**
2. Find the sale in the list (or use search/filter)
3. Click the sale number or row
4. View full details
