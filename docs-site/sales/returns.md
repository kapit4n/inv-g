# Returns

## What is it?

Process customer returns and issue refunds for previously completed sales.

![Returns](/screenshots/light/19-returns.png)

## How to Access

**Sidebar → Sales → Returns**. Route: `/sales/returns`.

## How to Process a Return

### Step 1: Find the Original Sale

Search by sale number, customer name, or date.

### Step 2: Select Items to Return

Choose which items from the sale are being returned and the quantity.

### Step 3: Select Return Reason

Choose a reason (defective, wrong item, customer changed mind, etc.).

### Step 4: Process Refund

Select refund method:
- **Cash** — Cash refund
- **Credit** — Credit to customer account
- **Original method** — Refund to original payment

### Step 5: Confirm

Review and confirm the return.

## Considerations

- Returns update stock quantities automatically
- A receipt is generated for the return
- Returns are linked to the original sale
- Partial returns are supported
