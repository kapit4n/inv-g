# Receipts & Daily Closeout

## Receipts

### What are Receipts?

Receipts are generated for every completed sale and return. They can be viewed, printed, or downloaded.

### How to Access

**Sidebar → Sales → Receipts**. Route: `/sales/receipts`.

### Viewing Receipts

1. Go to **Receipts**
2. Browse or search by sale number, date, or customer
3. Click a receipt to view details
4. Click **Print** or **Download** for a PDF copy

## Daily Closeout

### What is it?

The Daily Closeout summarizes all sales and cash register activity for a business day.

### How to Access

**Sidebar → Sales → Daily Closeout**. Route: `/sales/closeout`.

### How to Perform Closeout

1. Go to **Daily Closeout**
2. Select the **date** (defaults to today)
3. Review the summary:
   - Total sales by payment method
   - Cash register session details
   - Returns processed
   - Net revenue
4. Add **notes** if needed
5. Click **Close Day**

### What's Included

| Section | Content |
|---------|---------|
| Sales Summary | Total sales, count, average ticket |
| Payment Breakdown | Cash, card, transfer, credit totals |
| Returns | Returned amounts and count |
| Cash Register | Opening float, cash received, expected vs. actual |
| Notes | Admin notes for the day |

## Considerations

- Close out the cash register before performing daily closeout
- Daily closeout is a one-way operation for the day
- Historical closeouts can be reviewed for auditing
