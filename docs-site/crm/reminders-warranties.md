# Reminders & Warranties

## What is it?

Track service reminders and product warranties for customer vehicles.

## Service Reminders

### What are They?

Automated reminders for vehicle services — oil changes, inspections, part replacements.

### How to Access

**Sidebar → CRM → Reminders**. Route: `/crm/reminders`.

### Creating a Reminder

1. Go to **Reminders**
2. Click **+ New Reminder**
3. Select **Customer** and **Vehicle**
4. Set **Reminder Type** (oil change, inspection, etc.)
5. Set **Due Date** and/or **Due Mileage**
6. Add **Notes**
7. Save

### Reminder Status

| Status | Meaning |
|--------|---------|
| Pending | Not yet due |
| Due Soon | Approaching due date |
| Overdue | Past due date |
| Completed | Service performed |

## Warranties

### What are They?

Track product warranties issued to customers.

### How to Access

**Sidebar → CRM → Warranties**. Route: `/crm/warranties`.

### Creating a Warranty

1. Go to **Warranties**
2. Click **+ New Warranty**
3. Select **Customer**, **Vehicle**, and **Product**
4. Set **Warranty Period** (days/months)
5. Add **Terms** and **Notes**
6. Save

### Warranty Status

| Status | Meaning |
|--------|---------|
| Active | Under warranty |
| Expired | Warranty period ended |
| Claimed | Warranty claim processed |
