# Customers

## What is it?

Manage your customer database with contact information, vehicles, purchase history, and communication preferences.

![Customers](/screenshots/light/34-customers.png)

## How to Access

**Sidebar → CRM → Customers**. Route: `/crm/customers`.

## How to Create a Customer

### Step 1: Click "New Customer"

Click the **+ New Customer** button.

### Step 2: Fill in Information

| Field | Description |
|-------|-------------|
| Customer Type | Individual or Business |
| First/Last Name | For individuals |
| Business Name | For businesses |
| Phone/Mobile/Email | Contact info |
| WhatsApp | For messaging |
| Address, City, State | Location |
| Tax Number | For invoicing |
| Preferred Contact | How they prefer to be contacted |
| Preferred Language | en or es |

### Step 3: Save

Click **Save** to create the customer.

## Customer Detail

Click any customer to see:
- **Contact Info** — All contact details
- **Vehicles** — Registered vehicles with VIN, plates
- **Sales History** — All purchases
- **Credit Account** — Balance and transactions
- **Notes** — Internal notes and communication log
- **Timeline** — Activity history

## Customer Types

| Type | Use Case |
|------|----------|
| Individual | Walk-in retail customers |
| Business | Commercial accounts, workshops |
