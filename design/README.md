# Design

## Overview

This directory contains design assets, wireframes, and branding guidelines for Inventory Gear.

## Directory Structure

```
design/
├── wireframes/    # Low-fidelity wireframes
├── mockups/       # High-fidelity mockups
├── branding/      # Logo, colors, typography
└── README.md
```

## Design Principles

- **Minimal** — Clean interfaces, no clutter
- **Professional** — Commercial product feel
- **Accessible** — WCAG 2.1 AA compliance
- **Consistent** — Unified design language

- **Inter** — Primary UI font
- **JetBrains Mono** — Monospace for code and data
