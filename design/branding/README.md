## Color System

The application uses a neutral primary palette with semantic status colors.

### Primary Colors
- Indigo 700 (#4338ca) — Primary actions
- Indigo 500 (#6366f1) — Interactive elements
- Indigo 100 (#e0e7ff) — Primary backgrounds

### Status Colors
- Emerald 500 (#22c55e) — Success, positive
- Amber 500 (#f59e0b) — Warning, caution
- Red 500 (#ef4444) — Error, destructive
- Blue 500 (#3b82f6) — Info, neutral

## Typography Scale

| Element | Size | Weight |
|---------|------|--------|
| Page Title | 24px | Bold |
| Section Title | 18px | Semibold |
| Card Title | 14px | Semibold |
| Body | 14px | Regular |
| Small / Label | 12px | Medium |
